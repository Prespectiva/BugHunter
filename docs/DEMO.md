# Сценарий демонстрации BugHunter (≈ 10 минут)

Подготовка: `php scripts/init_db.php`, `php scripts/migrate.php`, `php scripts/seed_demo.php`,
`php -S 127.0.0.1:8000 -t public`.

| №  | Шаг демонстрации        | Что показать                                                                 |
|----|-------------------------|-------------------------------------------------------------------------------|
| 1  | Вход в систему          | tester@bh.local; затем неверный пароль — сообщение об ошибке                  |
| 2  | Список проектов         | Проекты BH и SITE, число ошибок, владелец                                     |
| 3  | Создание проекта        | Новый проект (код DEMO), проверка кода: 2–10 латинских букв или цифр          |
| 4  | Регистрация ошибки      | Заполнить форму, приоритет, получить ошибку со статусом New                   |
| 5  | Изменение статуса       | New → Review → Confirmed (tester); попытка перепрыгнуть — отказ               |
| 6  | Добавление комментария  | Комментарий под ошибкой, автор и дата; пустой комментарий не принимается     |
| 7  | Просмотр истории        | Переходы статусов с автором и временем                                        |
| 8  | Поиск и фильтрация      | Строка поиска + статус + приоритет, сортировка, вторая страница               |
| 9  | Аналитическая панель    | Dashboard: показатели, распределения, таблица по проектам                     |
| 10 | Права ролей (бонус)     | Вход customer: нет кнопок смены статуса; admin: все допустимые переходы       |
| 11 | Резервная копия (бонус) | `php scripts/backup.php`, затем `php scripts/integrity_check.php`             |
